0.5.1 测试版更新

- 修复 模型请求失败、重试次数设置得很大时，软件会卡死，只能退出重开
- 修复 请求重试时点停止要等很久，现在立即停止
- 修复 附件发送后，气泡里显示出一串「Attached files」和文件路径；现在只显示你打的字，文件以卡片形式显示，点击可打开
- 新增 Ctrl+V（Mac 上 Cmd+V）可直接粘贴在资源管理器或访达里复制的文件
- 优化 浅色主题改为柔和的米白色，文字更清晰；启动时不再先闪一下白屏
- 优化 窗口磨砂默认关闭，可在设置里打开
- 新增 设置 → 通用 → 对话宽度：自适应、标准、铺满；窗口拉宽时对话区跟着变宽
- 优化 很长的回复结束时内存不再突增
- 修复 卡片和消息的出场动画结束后，菜单偶尔点不开或关不上
- 修复已知问题
