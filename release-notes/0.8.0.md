0.8.0 测试版更新

- 优化 全新界面：标题栏、侧栏和对话区贴边排布，用细线分隔，字号、间距和浅色/深色配色都重新调整
- 新增 计划和子智能体以卡片显示在对话右侧，窗口较窄时收到顶部，点开查看
- 新增 快速切换模型：最近使用、推荐和置顶的模型，显示价格和是否在套餐内
- 新增 全部模型浏览：按厂商分组，旧版本收进「更多版本」，不稳定的模型有标记；可以按名称、厂商或「便宜」「国产」「看图」搜索
- 新增 自定义提供商可以给每个模型设置上下文窗口、最大输出、是否支持思考、能否看图和思考档位（含 Ultra）
- 修复 Windows 上找不到 Claude Code 和 opencode 的会话、部分 opencode 会话无法导入；读不了的会话会写明原因
- 修复 Mac 上窗口左上角的按钮和侧栏按钮没有对齐
- 优化 手机远程页面的计划和子智能体移到标题下方
- 修复已知问题
