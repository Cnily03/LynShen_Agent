0.10.4 测试版更新

- 新增 设置 → 网络：可设置代理，智能体的网页抓取、网页搜索和命令联网都走这个代理
- 新增 Claude Code / Codex 对话可以在 LynShen 上继续
- 新增 重新打开对话也能看到每轮回答用的模型和耗时
- 新增 压缩模型可选「跟随当前模型」
- 新增 手机远程页可以提交问题反馈，经电脑发送并附带电脑日志
- 新增 智能体可另开一个对话协助处理任务，并指定引擎、模型和推理强度
- 优化 手机远程页输入「/」列出命令并按命令发送，回退重写可用
- 优化 缓存未命中提醒默认关闭，可在 设置 → 通用 中打开；提醒不再说要等待
- 优化 网页搜索：先用当前模型自带的搜索，再用网关搜索，最后才用本机搜索，国内网络下更稳定
- 修复 Logo 显示异常、审阅 Markdown 文件只显示行号；审阅可打开所在文件夹、复制文件路径
- 修复 开机静默启动后，手机无法远程访问电脑
- 修复 iPad 上手机远程页侧栏按钮错位、深色模式下底部发白
- 修复已知问题
（内置 LynShen CLI 0.7.8）
